Q2. What is Measure of Dispersion in Statistics?

Measures of dispersion help to describe the variability in data. Dispersion is a statistical term that can be used to describe the extent to which data is scattered. Thus, measures of dispersion are certain types of measures that are used to quantify the dispersion of data.

  1. Range is the difference between the highest and lowest values in a dataset. ( how far apart the biggest and smallest numbers in a set are )
  2. Variance measures the average squared deviation of each data point from the mean of the dataset. it shows how much the numbers in a set are spread out from the average.
  3. Standard deviation is the square root of the variance. It is like variance but in a way that's easier to understand because it's in the same units as the original numbers.

  • Description of the Scatter graph

From the graph above, the function of the line is -0.396x+8.03, and there appears to be a negative correlation. However, since the R-squared value (Correlation Coefficient) is 0.063, the strength of the relationship is negligible. This indicates that there is no significant correlation between Outfit and Shyness. Please refer to the table below for further details.

Correlation Coefficient (R)

Strength of Correlation

± 0.61 to ± 0.80 : Strong correlation

± 0.41 to ± 0.60 : Moderate correlation
